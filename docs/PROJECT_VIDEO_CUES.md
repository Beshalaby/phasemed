# Phasmed project video cues

The Resolve timeline is 120 seconds, 1920×1080, with eight visual beats. The cut is intentionally silent so a recorded voiceover can be placed on a new audio track.

| Time | Visual | Voiceover |
| --- | --- | --- |
| 00:00–00:12 | Opening title: “Raw scans. Useful data.” | Medical imaging contains extraordinary detail—but most of that detail is trapped inside disconnected scans, measurements, and notes. Phasmed turns raw imaging into useful, inspectable data. |
| 00:12–00:28 | DICOM study cards move into a PatientModel card. | Start with the study. Import a DICOM study from a folder or imaging gateway. Phasmed validates the study, preserves its provenance, and compiles it into a persistent PatientModel. |
| 00:28–00:46 | CT slices become a structured anatomy object. | Instead of looking at isolated pictures, Phasmed turns volumes and segmentations into labeled objects with coordinates, measurements, and links back to the source images. |
| 00:46–01:04 | Model view linked to axial, coronal, and sagittal review cards. | Review the anatomy in 3D, then jump back to the linked source images. The model and the evidence stay connected. |
| 01:04–01:20 | Baseline and follow-up objects with a measured difference. | When a prior study is available, compare change over time with measured geometry—not just visual impressions. |
| 01:20–01:34 | Question card: “What changed near the nodule?” | Search attached context or ask a focused question. Answers are grounded in the model’s geometry, evidence, and measured change. |
| 01:34–01:48 | Procedure path and voice / gesture spatial view. | Use the same model in space: inspect relationships, explore a synchronized hologram view, or draw a planning trajectory. This is a planning visualization, not clinical guidance. |
| 01:48–02:00 | JSON export card and closing title. | When the work is ready to move downstream, export structured data for review, analysis, and AI. Phasmed: patient models in, useful models out. |

## Recording note

Record one continuous take at a calm pace, leaving short pauses at each time boundary. The visual cut already includes the section labels and arrows; the voiceover should sound like a guided walkthrough, not a list of interface controls.
